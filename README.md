# 신세계 크리스마스 - 포토부스

스크린 앞 스윗스팟(발자국 매트)에 서면 자동으로 3·2·1 카운트다운 후 사진을 찍어 보여주는 **비접촉 웹 포토부스**다.

```text
스크린 앞에 서요 → 3·2·1 자동 촬영 → 특별한 사진으로 변해요 → 사진을 받아요
```

## 현재 상태

- 1단계(개발용 정적 서버, 9:16 좌우 반전 카메라 미리보기, 카메라 상태·자동 회복)와 2단계(로컬 MediaPipe 얼굴 감지, "인식됨 / 인식 안됨" 임시 표시, 운영자용 인식 범위 조절·저장)가 끝났다.
- 3단계(촬영 한 사이클)는 구현을 마치고 검수 전이다. 인식 영역에 사람이 인식되면 자동으로 3·2·1 카운트다운 → 한 장 촬영(반전·9:16 원본 해상도) → 결과 10초 → 쿨타임 5초 → 대기로 돈다. 카운트다운 중 사람이 떠나면 취소하고, 쿨타임이 끝날 때 계속 서 있으면 바로 다음 회차를 시작한다. 운영자 키(`S`)로 수동 촬영도 할 수 있다.
- 현재 개발 범위는 **카메라 촬영부터 결과 화면 표시까지**다. 사진 효과는 TBD, 인쇄는 이후 범위다.
- PC 한 대에서 로컬 웹 서버(`localhost`)를 띄우고, 같은 PC의 브라우저를 전체화면으로 사용한다.

## 개발용 실행

저장소 루트에서 Windows PowerShell 5.1로 서버를 띄운다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File bin\server\serve.ps1
```

- Chrome에서 `http://localhost:8765/`를 연다. 포트를 바꾸려면 `-Port 8800`처럼 붙인다.
- `127.0.0.1`이 아닌 `localhost`로 접속한다(`127.0.0.1`은 400). 루프백(같은 PC)이 아닌 주소로 들어온 요청은 403으로 거절한다.
- `OBS Virtual Camera`가 있으면 그 장치를, 없으면 기본 카메라를 사용한다.
- `D` 키: 개발용 정보 표시 토글. 카메라 상태·오류 원인·재시도 횟수, 카메라 라벨, 실제 영상 크기, 9:16 영역 크기와 함께 감지 정보(delegate, 감지 시간·빈도, 얼굴 수·인정 수, 안정화 진행)를 보인다. 인식 영역(노란 점선)과 감지 박스(인정 초록, 제외 빨강)를 겹쳐 그린다.
- 카메라가 끊기거나 열리지 않으면 화면에 "준비 중입니다" 문구를 띄우고 자동으로 다시 연결한다.
- 외부로 나가는 요청은 `index.html`의 CSP로 막는다. 콘솔에 MediaPipe 사용 통계 전송(`odml.pa.googleapis.com`)이 차단됐다는 오류가 한 번 찍히는 것은 정상이다.
- 종료: 서버 창에서 Ctrl+C

## 운영자 단축키 (관람객용 아님)

| 키 | 동작 |
|---|---|
| `D` | 개발용 정보와 감지 박스 겹쳐 그리기 켜기·끄기 |
| `R` | 인식 범위 조절 화면 열기·닫기 (`Esc`로도 닫음). 열려 있는 동안은 인식에 의한 자동 촬영을 막는다 |
| `S` | 수동 촬영 시작 (대기 상태이고 카메라가 준비됐을 때만. 진행 중·쿨타임 중에는 무시). 수동 회차는 사람이 없어도 끝까지 찍는다 |
| `X` | 강제 초기화: 카운트다운·결과·쿨타임 어디서든 사진을 정리하고 바로 대기로 (쿨타임 없음) |

`Ctrl`·`Alt` 등 수정 키와 함께 누르면 무시한다. `D` 화면의 `session`·`capture`·`resources` 줄에서 촬영 상태, 실제 캡처 크기, 남은 이미지 자원 수를 볼 수 있다.

인식 범위 조절(`R`)은 마우스를 연결해 쓴다.

- 노란 사각형을 끌어 인식 영역을 옮기고, 모서리·변의 핸들로 크기를 바꾼다.
- 슬라이더로 최소·최대 얼굴 크기, 최소 신뢰도, (고급) 판정 시간을 바꾼다. 영역 가운데의 파란·보라 사각형이 최소·최대 얼굴 크기 기준이다.
- 바꾸는 즉시 인식 판정에 반영되고, 감지된 얼굴은 초록(인정)·빨강(제외)으로 보인다.
- **저장**을 눌러야 이 PC의 브라우저(`localStorage`)에 남는다. 저장하지 않고 닫으면 저장된 값으로 돌아간다. "취소"는 저장된 값으로, "기본값으로"는 기본값으로 되돌린다.
- "현재값 JSON"을 열어 값을 복사해 둘 수 있다.

자세한 규칙은 [docs/SYSTEM.md](docs/SYSTEM.md) 5절 "인식 범위 조절"을 따른다.

## 테스트 (개발 PC 전용)

인식 판정·설정, 감지기 재생성, 영역 끌기, 촬영 상태 기계, 캡처 영역 계산의 Node 테스트다(`tests/`). Node 22 이상(`node --test`의 glob 인자 때문, 개발 PC는 Node 24.19.0으로 확인), 의존성 설치는 필요 없다.

```powershell
npm test
```

## 라이브러리 갱신 방법 (개발 PC 전용, 현장 불필요)

MediaPipe 런타임·모델은 `lib/mediapipe/`에 커밋되어 있다. 현장 PC는 clone만 하면 되고 Node·npm·인터넷이 필요 없다. 버전을 바꿀 때만 개발 PC(Node 18 이상)에서 실행한다.

```powershell
npm install
npm run vendor:mediapipe
```

버전 변경, 해시 갱신, 검증 절차는 [docs/SYSTEM.md](docs/SYSTEM.md) 5절 "MediaPipe 로컬 라이브러리"를 따른다.
