## 제안한 가안과 이유

- **반전은 웹에서만 처리:** 이중 반전을 막고, OBS 없이 웹캠을 직접 연결해도 같은 결과를 얻기 위해서다.
- **Face Detector 우선, 판정 단계 시간 필터:** 사용자는 MediaPipe가 다인원일 때 스무딩이 적용되지 않았던 경험이 있다. 이 프로젝트는 감지 좌표를 그리지 않고 "영역 안 사람 유무"만 쓰므로 좌표 스무딩이 필요 없다. short-range 모델의 약 2m 범위도 요구 거리와 맞는다.
- **결과 10초 기준:** 인쇄 연동 전에는 "출력 인식" 신호가 없으므로 결과 표시 시작 시점을 기준으로 대체한다.
- **참고 프로젝트 구조:** PowerShell `HttpListener` 정적 서버, `Launch.bat` → `launch.ps1`, `settings.ini`, OBS `--startvirtualcam` 실행, Chrome `--app` 전용 프로필, 빌드 없는 ES 모듈, 로컬 MediaPipe. 참고 프로젝트의 최초 커밋(`b813a71`)이 최소 서버·런처의 좋은 기준이다. AI·결제·NAS·워치독·자동 업데이트는 가져오지 않는다.
