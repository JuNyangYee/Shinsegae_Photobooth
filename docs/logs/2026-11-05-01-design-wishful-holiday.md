## 시안 컨셉

**"붉은 크리스마스 카드 한 장"** — 9:16 화면이 카드이고 가운데 사진 창(4:5)으로 관람객이 들여다보인다.

- 위 띠: 필기체 "Puuvilla Story Begins" + 금박 "A WISHFUL / HOLIDAY". 카운트다운 동안은 표제가 물러나고 같은 자리에 큰 금박 3·2·1(카메라가 화면 위에 있으니 시선이 위로 간다).
- 창 윗선 오른쪽에 솜송이가 앉아 있다: 사람이 서면 창 쪽을 내려다보고, 셔터에 움찔, 결과에 눈웃음, 준비 중에는 잠든다.
- 아래 띠: 한국어 안내(크림색) + 작은 대문자 금색 영어 줄 + 날짜·시각. 결과에서는 아래 띠가 눈 쌓인 흰 카드 끝으로 덮이고 표제 금박 위로 빛이 한 번 지나간다.
- 눈은 위·아래 띠 안에서만 내리고 창 안에는 아무것도 두지 않는다(보이는 그대로 찍힌다). 흑백 유화 사진이 붉은 카드·금박 사이에 놓이는 대비를 노렸다.
- 운영자 패널: 짙은 버건디 바탕 + 금색 강조. 필터 섹션 맨 위에 시험 조합.

| 유화 끔 = 유화 패스를 건너뛰고 같은 입력에 출력 단계만 | 표시 흉내가 아니라 실제 처리. 카메라 처리 경로(반전·회전·확대·색 보정)와 출력 단계(회색조·레벨·감열지 점·인쇄 데이터)는 그대로라 미리보기 = 결과 규칙이 유지된다. 유화 수치는 건드리지 않는다 |
| 유화 끔이면 감열지 흑백 스타일은 톤 점 | 붓 결 선·흐름 선·질감 강조는 획·흐름장이 있어야 한다. 저장한 스타일은 그대로 두고 쓰지 않는다(`bwStyleOf`) |
| 유화 끔은 30장/초 (`OIL_OFF_FPS`, 가안) | 획이 없는데 12장 스톱모션이면 원본이 끊겨 보인다. 패스 2개라 가볍다 |
| 컬러 조합은 인쇄 데이터 없음 | "화면 컬러 시험과 인쇄용 흑백 데이터를 구분"(위임 조건). 인쇄 데이터는 늘 1비트이고 흑백 방식이 회색조 유화·감열지일 때만. 현장 `gray`는 예전처럼 인쇄 데이터가 없다 — 이 시안에서도 바꾸지 않았다 |
| 조합은 저장 대상(다른 필터 값과 같은 규칙) | 시험 후 그 조합을 쓰기로 하면 저장하면 되고, 저장하지 않고 닫으면 저장된 조합으로 돌아간다(실행 중 값 = 재시작 값 규칙). 키 두 개는 선택 키라 예전 파일이 "고쳐 씀"이 되지 않는다 |
| 인쇄 쪽: 배치 그대로, 글자만(표제·날짜 / 필기체·시각·용지 폭) | 감열지 길이·확인 기준(576×912)을 바꾸지 않고 캠페인 표기를 넣었다. 필기체 획이 203dpi에서 끊기는지는 실제 용지로 봐야 한다 |
| 데모에 "현장 저장값 (대조본)" | 현장 수치(강도 0.05 등)의 실제 모습을 카메라 없이 본다. 값은 읽기 전용으로 대조한 것을 코드에 적었고 파일을 읽거나 쓰지 않는다 |

## 남은 문제와 미검증

- **사용자 검토·채택 전이다.** 오케스트레이터 기술 검수와 사용자 디자인 검토가 남았다. 채택되지 않으면 이 브랜치는 그대로 두고 IMPRINT를 쓴다.
- 실제 사람 얼굴로 자동 시작·이탈 취소를 이 시안에서 확인하지 않았다(가짜 카메라에는 얼굴이 없다. 자동 시작 판정 코드는 바뀌지 않았고 Node 테스트로만 확인).
- 실제 감열지 출력: 필기체·Cinzel 글자 획, 4조합 중 흑백 방식별 점 결과 — 프린터 연동이 없어 미검증.
- 4K 키오스크 화면, 현장 조명에서의 금박 글자 대비, 솜송이 SVG 필터의 저사양 PC 비용 — 미검증. 유화 끔 30장/초가 현장 PC 4K 입력에서 버거우면 낮춘다(가안).
- Cinzel·Pinyon은 latin 부분 집합이라 영어 문구에 그 밖의 글자를 넣으면 시스템 서체로 떨어진다(서체 검사가 막는다).
- "기본값으로"는 개발 PC 기본 수치(강도 0.3 등)로 돌아간다(예전과 같은 규칙). 현장에서 조합만 시험하고 원래 값으로 돌릴 때는 "취소"나 닫기를 쓴다.
