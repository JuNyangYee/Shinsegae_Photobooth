### 밝기·대비·감마가 어디에 쓰이는지 (코드 확인)

회색조 유화(`gray-oil`)에서 세 값은 **화면 미리보기와 결과 사진, 인쇄 데이터에 모두** 같은 값으로 쓰인다. 사용자가 화면에서 보고 고른 값이 화면에 그대로 적용된다.

- 화면 미리보기·결과 사진: `effect/oil-renderer.js`가 출력 단계 `FS_OUTPUT`에 `uGray`(회색조 유화·회색조면 1)와 `levelUniforms(settings)`를 넘긴다(`canvas`·`pixels`·`warm` 모두).
- 인쇄 데이터: 같은 합성 그림을 `thermalStage`(톤 점)로 줄일 때 `FS_THERMAL_REDUCE`에 같은 레벨을 넘긴다. 화면 출력에 레벨을 입힌 뒤가 아니라 합성 그림에서 한 번만 입힌다.
- 효과를 못 그린 원본 사진 대체: CPU `grayLevelsInPlace(…, settings)`로 같은 레벨을 입히고, 인쇄 데이터는 그 회색 사진에서 중립 레벨로 줄인다(두 번 입히지 않음).
- 끔(`off`)에서는 쓰지 않는다.

### 브라우저 확인 도구

- **사진 효과 미리보기:** 조절값 파일이 없을 때 D `values` 줄이 새 기본값(`strength 0.3 size 1.3 … refine 0.3 … brightness -0.05 contrast 1.5 gamma 1.3 (defaults …`)인지 확인을 더했다.

- **새 그림 판정:** 그림 기록기(`EFFECT_READER`)는 캔버스 중앙 8×8 화소가 모두 0이면 "이번 화면 갱신에는 그리지 않음"으로 봤다(지운 버퍼는 0이고, `alpha: false`라 알파로는 구분하지 못한다). 새 레벨(대비 1.5·밝기 −0.05)에서는 실제 OBS 장면 중앙이 순수 검정이 되어, 실제 카메라의 회색조 유화 기본값 촬영에서 그림을 하나도 기록하지 못하고 실패했다(`drawings: []`). 가운데 가로·세로 한 줄씩을 보도록 바꿨다.

## 남은 문제

- **새 레벨에서 어두운 장면이 크게 검정으로 뭉친다:** 개발 PC OBS 장면 기준 결과의 79%가 순수 검정이었다. 사용자가 화면을 보고 고른 값이라 그대로 두었다. 현장 조명에서 확인하고, 필요하면 `E`에서 다시 조절해 저장한다.
