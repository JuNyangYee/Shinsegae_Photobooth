# 18단계 — 카메라 영역 확대와 상하 캐릭터 배치

## 사용자 요청과 완료 기준

- 17단계 카메라 영역이 작고 나무틀이 답답하며, 네 캐릭터가 아래에 몰려 답답하다는 사용자 피드백을 반영한다.
- Opus 5.5가 디자인을 맡아 사진 창의 실질 면적을 늘리고 목재 두께·여백을 조절한다. 푸빌라·후트는 위, 깨또·포코는 아래를 기본으로 포즈와 상대 크기를 설계한다.
- 전체 9:16와 기존 사진 3:4를 기본으로 유지하며 구체적인 창 좌표는 Opus가 현재 화면을 직접 본 뒤 정한다. 얼굴 중심과 하단 눈 홈 안내를 가리지 않는 것이 기준이다.
- 수정 후 간단 검수, 필요한 수정과 간단 확인을 거쳐 `master` 병합·기존 `origin`으로 정상 push까지 사용자 요청 범위다.

## 유지할 동작

- 무필터 3D 생성 원본, 알갱이 압설 눈벽 2단, 자연스러운 DOF, 공식 캐릭터 레퍼런스와 척도.
- 최종 전체 화면 유화, 화면과 사진의 같은 유화 설정·seed·셔터 프레임, 장식의 인쇄 제외, 감열지 점 위에 유화를 다시 적용하지 않는 17단계 계약.
- 상단 관람객 UI 없음, 하단 눈에 파인 문구와 숫자, 게이지 표시 없음.
- 창 좌표 변경은 사진 크롭·결과·실패 대체 표시·감지 ROI·D 표시·감열지 점·데모·장면 키 범위에 일관되게 연결한다.
- 현장 `config/*.local.json`은 수정하지 않는다. 실제 촬영 프레임은 저장하지 않는다.

## 남은 문제와 바로 다음 작업

### Opus 구도 결정 (구현·이미지 생성 기준)

- 사진 창은 1080×1920 기준 x60~1020·y250~1530, **960×1280(3:4)**. 기존 810×1080 대비 면적 +40.5%다. 캐릭터가 가린 면적까지 뺀 증가율은 생성 후 실제 측정 전에는 추정으로만 둔다.
- 나무는 한 겹 각재로 기둥 36px, 위 들보 38px, 아래 레일 16px. 좌우 24px에 DOF 배경이 보인다.
- 위 왼쪽 푸빌라는 들보 뒤에서 머리·목도리·앞발이 보이고, 위 오른쪽 후트는 들보에 앉는다. 아래 오른쪽 깨또는 눈벽 위에 서고, 아래 왼쪽 포코가 자리한다. 얼굴 중심 x200~880·y270~1230은 비운다.
- 눈벽은 y1540~1690, 눈 바닥은 1690부터이며 글씨는 y1700~1880에 둔다. 최종 원본 수신 후 실제 키 경계와 바닥 위치를 재측정한다.
- 인쇄 격자의 창은 512×683점(가로 열 32~544, 세로 줄 133~816)으로 세로 정확값 682.67을 반올림한다. 같은 영역·반올림 규칙을 화면과 인쇄에서 써 점 일치를 유지한다. 인쇄 쪽은 576×875점 계획이며 구현·검증 후 확정한다.

- Opus가 확장 창 좌표·목재 두께·상하 캐릭터 구성과 이전 대비 면적을 정해 이미지 담당에게 전달한다.
- Astra가 원본을 수정하고 실측값을 공유하면 Opus가 실제 합성에서 답답함·인물 영역·안내 배치를 확인한다.
- 변경 관련 검사와 간단 검수 후 병합·push한다. 실제 장치·현장 거리·4K·실물 인쇄는 수행한 경우에만 완료로 보고한다.
