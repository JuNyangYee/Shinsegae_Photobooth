## 사용·운영 기준

- 촬영 회차가 끝나면 `E` → 필터에서 업데이트 확인 → 후보 시험 → 필요하면 가져온 기본값 적용 → 적용·저장을 사용한다. 이전판 복원은 엔진과 당시 수치를 함께 되돌린다.
- 확인만으로 현재 영상·미저장 수치·저장판을 바꾸지 않는다. 새 후보는 시험을 통과해야 적용할 수 있다.
- 업데이트 다운로드에만 인터넷을 사용하고, 평상시에는 기본판 또는 저장판으로 오프라인 동작한다. 현장 Node 설치는 필요 없다.
- 지원하는 원본 데이터·GLSL 변화만 가져온다. 새로운 항목·지원 밖 실행 규칙·동적 선언은 조용히 누락하지 않고 검토 필요로 보류한다. 원격 JS는 실행하지 않는다.
- 별도 MOODS 후처리와 캐릭터 normal/mask는 현재 카메라 유화 경로 밖이다. 전체 22항목 대응과 복원법은 [SYSTEM](../SYSTEM.md)의 13단계 절에 있다.
