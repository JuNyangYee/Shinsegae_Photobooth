# 14단계 — 생성 이미지와 역할 분리

## 현재 상태

- 기본 내장 imagegen 도구로 배경과 그린 전경 1차 이미지를 생성한 뒤, 사용자 후속 지시에 따라 배경·얼음벽을 포함한 통합판을 생성했다. 아직 최종 자산 확정·앱 적용·검증 완료가 아니다.
- 사용자 확정: **구도·UI·WebGL 설계는 Opus 5.5**, **이미지 생성·수정은 별도의 GPT-6 Astra / medium / auto 세션**이 맡는다. 오케스트레이터는 전달·통합 담당이다.
- 생성 중 바뀐 요청: 푸빌라·너구리 포즈 변경, 전체 상대 크기 조정, 카메라 창만 크로마키, 바깥 배경 통합, 여우를 얼음벽 위로 올림, 벽 아래 눈바닥에 안내.
- 안내 문구와 카운트다운 숫자는 그림에 굽지 않고 상태별 교체가 가능한 DOM으로 **하단 눈바닥에 새긴 느낌**을 구현한다. 사용자 후속 확정으로 상단에는 숫자를 포함한 UI가 전혀 없다. 날짜·시각도 표시하지 않는다.

## 디자인 담당의 좌표 규격

- 전체 1080×1920 비율. 카메라 창 x0~1080, y240~1590(4:5), 위 들보 y222~258, 아래 들보 y1572~1608.
- 얼음벽 y1608~1710, 안내를 위한 눈바닥 y1710~1920. 창만 #00FF00 단색이며 창을 덮는 캐릭터 부분은 불투명하다.
- 같은 척도의 기립 키: 푸빌라 412 / 깨또 264 / 후트 240 / 포코 108px(103:66:60:27). 포즈 때문에 보이는 크기는 다르나 머리·몸의 상대 척도는 유지한다.
- 푸빌라: 위 왼쪽 x50~330/y40~290, 들보 뒤에서 허리 위만 보이며 두 벙어리 손을 들보에 얹고 가운데를 내려다봄.
- 후트: 위 오른쪽 x790~1010/y30~310, 들보 위에 앉아 다리를 늘어뜨리고 한 팔로 위를 가리킴.
- 깨또: 아래 왼쪽 x40~260/y1348~1612, 얼음벽 윗면에 서서 손 흔듦. 포코: 아래 오른쪽 x900~1040/y1466~1576, 들보 위에 앉아 작은 눈덩이를 듦.

## 생성과 한계

- 1차 전경은 들보 위치와 크기가 규격과 달라 폐기 후보로 보존했다. 통합판도 생성 도구가 요청한 좌표와 상대 크기를 정확히 지켰는지 후속 이미지 담당이 확인한다. 그림을 보고 완료라고 단정하지 않는다.
- 도구 참조는 최대 5개다. 통합판에는 새 배치 가이드, 1차 배경, 1차 캐릭터, 공식 네 캐릭터 척도표, 푸빌라 턴어라운드를 사용했다.
- 원본 참고 자료는 프로젝트 밖의 시퀀스 자산을 읽기만 했다. 최종 채택 그림은 저장소 자산 폴더에 복사하여 외부 경로 의존을 없앤다. 중간 생성물은 Git 제외 `artifacts/stage14/generation/`에 보관한다.
- 실제 영상 생성은 이번 범위에 없다. 미래에는 같은 창 좌표·키 색을 사용하는 영상으로 장식판을 교체할 수 있게 한다.
