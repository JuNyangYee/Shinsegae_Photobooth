## 남은 문제

- **SYSTEM이 목표 1/3(약 71KB)보다 크다(97,944바이트, 46%).** 이력·측정·검수 기록·중복은 걷어냈고, 남은 것은 현재 규칙·설정·경로·장애 동작과 화면·운영자 패널·D 화면의 구체 값이다. 더 줄이려면 관람객·운영자 화면의 CSS 수치, D 줄 문자열, 감지기 생성 실패 정리 절차, 감열지·흑백 스타일 내부 같은 구현 세부를 코드 주석으로 옮기고 SYSTEM에서 빼야 한다. 코드 변경이 따르므로 이번 범위(문서만)를 넘어 하지 않았다.
- 브라우저 확인 소요 시간(약 4분)은 다시 재지 않았다.
- 기존 로그의 남은 문제(현장 실측, 현장 PC 성능, 실제 프린터, 원본 필터 권한 등)는 PROJECT 5절 "남은 일"로 모았다.
