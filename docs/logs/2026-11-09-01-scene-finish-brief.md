# 17단계 — 눈벽·DOF·캐릭터 일관성과 최종 화면 필터

## 사용자 요청

- 첨부 이미지의 눈 알갱이 질감과 둥근 모서리가 있는 불투명 눈블록 담벼락을 따른다. 나무틀과 전체 장면에 자연스러운 DOF를 적용한다.
- 시퀀스 프로젝트 `00_Sequence_Gen`의 공식 캐릭터 레퍼런스를 직접 확인해 얼굴·의상·포즈·상대 크기의 일관성을 높인다.
- 하단 게이지는 제거하거나, 안내 글과 위치를 맞춰 눈에 쓴 표현으로 바꾼다. 기존 평면 게이지가 어색하게 남지 않게 한다.
- 생성 이미지는 필터가 없는 원본으로 만든다. 필터는 합성된 화면 전체의 마지막 단계에 적용한다.
- `004_PuvillaMirror` 프로젝트의 실제 필터 로딩 방식을 조사하고 이 앱에서도 같은 방식으로 불러올 수 있게 한다. 외부 프로젝트는 조사용이며 런타임 절대 경로 의존성을 만들지 않는다.
- **새 Opus 5.5 high auto 세션**, **새 GPT-6 Astra medium auto 이미지 세션**을 사용한다. 작업 후 **병합과 push까지 사용자 승인**했다.

## 보존 기준과 조사 사항

- 전체 화면 9:16, 카메라 개구부 3:4와 좌우 여백, 상단 관람객 UI 없음, 하단 눈 홈 안내·숫자를 유지한다.
- 생성 이미지에 유화·후처리·글자를 굽지 않는다. 최종 화면 필터와 기존 카메라 효과의 중복 처리를 없애고, 실제 사진·흑백 감열지 출력과 화면 장식의 경계를 명시한다.
- 기존 유화·흑백 독립 시험과 유효한 저장 수치를 유지한다. 현장 `config/*.local.json` 원본은 수정하지 않는다.
- Mirror의 필터 정의·수치·로딩·실패 복원 방식은 실제 코드 조사 후 구체화한다. 아직 확인하지 않은 동작을 구현 완료로 쓰지 않는다.
- 사용자 첨부와 공식 참고는 자산 담당이 직접 열어 확인한다. 카메라 창만 크로마키로 비우는 규약과 실제 합성 좌표를 구현 담당과 먼저 맞춘다.

## 남은 문제와 바로 다음 작업

### 진행 중 사용자 확정

- 화면 필터가 켜졌을 때 **화면에서 본 유화 느낌을 사진에도 반영**한다. 장식은 사진에 넣지 않으며 유화 뒤 감열지용 흑백 변환을 적용한다. 구현·검증 기록은 02 로그에 둔다.
- 검수 등 Codex 세션 권한은 **`auto-review`**로 변경한다. 사용자가 모드 변경 과정에서 잠시 중단했고 재개를 요청했다. 새 Sol 검수 세션과 이번 Astra 이미지 세션을 이 모드로 설정했다. 완료한 검사를 반복하지 않고 남은 범위부터 이어간다.

- Opus가 Mirror의 필터 구조와 화면 합성 접점을 확인해 설계를 공유한다.
- 두 담당자가 프레임 좌표·캐릭터 척도·DOF 초점을 맞추고 코드와 자산을 구현한다.
- 관련 경로와 합성 화면을 확인하고 간단 검수 후 master에 병합한다. 원격 상태를 확인해 정상 push하며 강제 push하지 않는다.
- 실제 장치·현장 조명·4K·실물 인쇄는 실제 수행한 범위만 완료로 보고하고 나머지는 미검증으로 남긴다.
