## 화면 방향

- 제공한 시퀀스 프로젝트의 공식 캐릭터 원형과 최신 v09 배경·심도 방향을 참고한다. 원본 프로젝트는 읽기만 하고 런타임 의존하지 않는다.
- 가운데 사진 창은 현재 비율을 유지하면서 위로 올린다. 상단 제목·문구는 없앤다.
- 캐릭터가 사진 틀 윗선에 걸터앉거나 손을 걸치고, 일부는 틀 앞에서 함께 포즈를 잡는다. 사용자가 첨부한 배치 스케치를 기준으로 한다.
- 배경은 눈 덮인 마을을 조금 위에서 내려다보는 느낌이며 DOF로 흐린다. 최신 참고의 보라·파랑 하늘과 은은한 복숭아빛 지평선, 따뜻한 조명에 맞춘다.
- 하단은 `발자국 위에 서주세요`와 자연스러운 영어 안내를 둔다. 날짜·시간은 표시하지 않는다. 눈에 새긴 글씨 느낌을 검토하되 가독성을 우선한다.

## 합성·이미지 생성 경계

- 실제 생성 이미지로 배경과 캐릭터 장식을 만든다. 캐릭터는 공식 3D 원형·의상·비율을 유지한다. 푸빌라 손은 벙어리장갑 형태, 발에는 발가락 홈을 만들지 않는다.
- 배경 / 카메라·촬영 결과 / 사진 틀·캐릭터 전경 / 상태 안내 레이어를 분리한다. 장식은 화면용이며 촬영 사진·감열지 데이터에 섞지 않는다.
- 생성 전경의 카메라 자리는 비어 있는 단색으로 두고, 나중에 알파 없는 캐릭터 영상을 크로마키로 교체할 수 있도록 위치·키 색·레이어 규칙을 기록한다. 이번 범위에는 영상 생성이 없다.
- 생성 자산은 저장소 안에 보관하며 개인 PC 외부 경로에 의존하지 않는다. 원본 참고 이미지·실제 카메라 프레임은 Git에 넣지 않는다.

## 체험 흐름

1. 대기: 카메라 창과 캐릭터, 하단 발자국 안내.
2. 인식: 기존 인식 기준을 쓰고 준비 상태를 간결하게 안내.
3. 카운트다운: 사진을 가리지 않는 위치에 숫자 표시. 상단 상시 제목은 없음.
4. 셔터·처리: 기존 실제 촬영 경로 유지, 과한 효과 없이 전환.
5. 결과: 같은 사진 창에 결과를 표시. 실제 프린터 완료를 가장하지 않음.
6. 쿨타임·복귀: 기존 저장 시간에 따라 안내를 바꾸고 대기로 복귀.
