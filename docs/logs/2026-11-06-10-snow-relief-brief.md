# 15단계 — 눈 블록 벽·전체 장면 유화·파인 눈 글씨

## 사용자 수정 요청

1. 기존의 투명한 푸른 얼음벽은 잘못 해석한 것이다. 눈던지기 시퀀스에 나오는 이글루처럼 **눈 블록을 쌓은 불투명한 벽**으로 바꾼다. 눈 블록의 둥근 모서리·줄눈·압설 질감을 참고한다.
2. 카메라 사진뿐 아니라 **캐릭터와 배경을 포함한 전체 장면에도 유화 필터**를 적용한다. 나무 프레임·벽·눈바닥을 포함해 효과가 빠진 장식 영역이 없어야 한다.
3. 하단 글씨는 색으로 쓴 글자가 아니라 **발자국처럼 눈이 파인 형상**이다. 안내·영어·카운트다운 숫자에 눈 안쪽의 깊이·음영·가장자리·눈 표면 느낌을 표현한다.

## 보존할 것

- 화면 9:16, 사진 창 4:5·240~1590줄, 현재 캐릭터 포즈·상대 크기와 배치.
- 상단 관람객 UI 없음. 문구·숫자는 하단 눈바닥에서 교체한다. 날짜·시각 없음.
- 기존 카메라 유화·흑백 독립 시험, 톤점 혼합, 촬영·인식·취소·복구 기능 및 현장 설정.
- 장식은 화면에만 합성한다. 장식용 효과가 카메라에 중복 적용되거나 감열지 미리보기·최종 출력 일치를 깨뜨리지 않게 처리한다.
- 카메라 창만 크로마키인 통합 장면 구조와 미래 알파 없는 영상 교체 규격.

## 역할과 구현 기준

- Opus 5.5: 구도·UI·유화 처리·동적 눈 파임 표현. 정적 장면은 필요할 때만 처리하고 불필요한 매 프레임 작업을 피한다. 구체 효과 방식과 가안 수치는 구현 로그에 남긴다.
- GPT-6 Astra / medium / auto: 눈던지기 시퀀스 원본을 직접 확인하고 벽 이미지를 국소 수정한다. 유화가 이미지와 런타임에 중복 적용되지 않도록 Opus와 먼저 협의한다. 동적 문구를 배경에 임의로 굽지 않는다.
- 오케스트레이터: 사용자 요청 기록·연결·간단 검수 요청·통합. 기존 판은 `backup/snow-frame-2026-11-06` (`63d4687`)으로 보존한다.
- 검수는 기존 사용자 확정대로 GPT-6.1 Sol / xhigh / auto 간단 검수 1회, 필요한 수정 뒤 해당 부분 간단 확인만 한다. 본격 검수는 별도 요청 때 진행한다.

## 남은 문제와 바로 다음 작업

- 이미지 담당이 눈벽 참고를 찾고 Opus와 수정 범위를 합의한다.
- Opus는 실제 유화 적용 방식 및 눈 파임 렌더링을 구현하고, 합성 화면에서 기존의 평면 글자와 구별되는지 확인한다.
- 완료 뒤 현재 기준 문서 PROJECT/SYSTEM과 구현·이미지 로그를 갱신한다. 본 로그는 요청과 범위이며 아직 구현 완료를 뜻하지 않는다.
